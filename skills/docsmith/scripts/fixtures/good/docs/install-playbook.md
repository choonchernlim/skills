# Install the Client

> **Audience:** new engineers setting up a workstation.

The client talks to the API, so every workstation installs it first.

## Install

<!-- frozen: the vendor removed every older release from its feed -->
Install client 4.12.3, the oldest release the feed still serves.

The key used to sign each request lives in your keychain.

The bucket used to hold the client cache is versioned, and the client lists builds made in the past 30 days.
